Button Styles（按钮样式与状态）

Primary Button（主要行动）

主按钮使用高对比色与轻阴影，Hover/Active 提供即时反馈；语义化文案体现指示性。

Secondary / Ghost（次要行动）

See Form

次要按钮降低视觉权重以避免与主 CTA 竞争；Ghost 用于卡片内部的轻量动作。

Forms（表单：校验 / 提交 / 反馈）

Demo Form（前端校验演示）

使用浏览器内置校验（required/email/minlength）；成功/失败消息通过 `aria-live` 公告。
