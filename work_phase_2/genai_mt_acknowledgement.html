Genai Mt Acknowledgment

Acknowledgement of Tools Used

ChatGPT: Primarily used in this project for generating JavaScript examples, explaining CSS syntax, debugging navigation bar issues, and providing suggestions for layout optimization and responsive design.

Grammarly: Used to improve the fluency, coherence, and tone of my writing, ensuring professional expression in documentation.

Prompts and Interaction Process

I adopted a multi-step prompting strategy when working with AI tools.

For example, when I wanted to implement a mobile collapsible navigation bar, I provided my existing HTML and CSS files to ChatGPT and asked:
“How can I make a mobile-friendly collapsible navigation bar? Is my current HTML and CSS setup feasible? Please give me some JavaScript examples.”

At times, ChatGPT provided incorrect answers or altered parts of the code that were already correct. In such cases, I usually attempted manual modifications and verification first. If the issue remained unresolved, I followed up with another question, such as:
"Why doesn't my navigation bar open? The JavaScript doesn't seem to be working. Please explain in detail why this error occurs and provide examples."

Eventually, I discovered that the root cause was a spelling error in the JavaScript file path, which prevented the script from being loaded properly. This experience reinforced the importance of combining AI advice with manual verification.

In addition, layout issues were the most frequent topics I consulted ChatGPT about:

  • “This card is too wide. Please suggest improvements.”
  • “How can I adjust the spacing between text elements?”
  • “How can I adapt the layout for mobile devices?”

In these scenarios, ChatGPT's responses were often very useful. As the project progressed, I became capable of independently debugging and optimizing layouts without needing further AI assistance.

Critical Evaluation of AI Outputs

AI outputs are not always reliable, so I maintained a practice of critical evaluation:

  • I never applied ChatGPT's suggestions blindly. Instead, I used the browser's Inspect tool to cross-check DOM and CSS information. This allowed me to test modifications directly in the browser. If the results were satisfactory, I then applied them to my actual code.
  • This method was especially effective for layout adjustments, since browser changes reset upon refresh, avoiding the risk of permanent negative effects.
  • Without critical thinking, following ChatGPT's suggestions could easily lead to more complicated or incorrect outcomes.

In terms of color scheme suggestions, ChatGPT performed poorly. The palettes it suggested were visually unappealing and failed to meet WCAG 2.2 accessibility standards. As a result, I chose to reference professional websites for color design rather than adopting AI outputs.

During the writing process, I relied more on Grammarly to refine clarity and professionalism. In contrast, ChatGPT's summaries often contained inaccuracies or fabricated details. Even when provided with all relevant files, its outputs lacked depth and insight, and sometimes hindered my critical thinking. Therefore, I treated AI-generated text only as inspiration, not as final results.

Challenges and How I Addressed Them

The biggest challenge I faced was that ChatGPT occasionally fabricated answers based on the information I provided.

To address this, I developed two main solutions:

  • Rephrasing questions: If the issue stemmed from ambiguous wording, I cleared the conversation history and asked the question again with clearer phrasing.
  • Manual code inspection: If the problem persisted, I manually reviewed the HTML and CSS files. In practice, broken file links were among the most common causes, and manual checking almost always resolved the issue.

These two steps were sufficient to handle most errors and allowed me to quickly identify the root cause.

Impact on Productivity and Creativity

Despite these challenges, ChatGPT significantly improved my workflow:

  • In the early stages, when I was not yet familiar with CSS, ChatGPT provided suggestions thathelped simplify lengthy CSS code and taught me to reuse common patterns, which saved considerable time.
  • It reduced the time I spent on repetitive debugging and styling, enabling me to focus on accessibility design and higher-level functionality.
  • Over time, I developed stronger critical thinking skills when evaluating AI outputs, which not only improved efficiency but also enhanced my creativity and independence in problem-solving.
